What's New in TrafxPLAN Sign (formerly KeySIGN)

 

Version 2026.0.0 - Feb 2026

  1. Renamed to 'TrafxPLAN Sign', to fit into a suite of TrafxPLAN software.
  2. Roundtrip adjusted to handle when poosts have no foundations.
  3. 515 with multiple chevrons now asks if a yellow backing is required.
  4. 606A and 606R added to the Sign and Supp Plate function.

 

Version 21.5.2 - May 2025

Compatibility with R2026:

  1. Signs to 2702, 2703 and 7305 added to thumbnails.
  2. A lot of Welsh signs added to library, over 250 extra signs added.
  3. So many Welsh signs that now the Welsh library has been split up into 4 sections to make finding signs easier.
  4. Fix for Underline command when no nogo layer present.
  5. Diag 670 roundels now have a 1500 size option.
  6. 7404 on two lines now have the correct line spacing.
  7. Double click for certain library signs now fixed.
  8. Diag 572 fixed for the Welsh 'Llath/yards' option.

 

Version 21.5.0 - October 2024

Compatibility with R2025:

  1. Stub arm lengths fixed on arcs and lines.
  2. 2506 P+car symbol fixed when facing right.
  3. Welsh hyphen size fixed.
  4. Welsh 20 dragon added.
  5. Welsh signs added for 545.3, 557.2, 880.2 and 883.1
  6. Welsh compass points abbreviations corrected.
  7. Sign877 option for Except buses is now in correct lower case.
  8. Width of flag sign with pointed tip now fixed.
  9. Parking patch in 660.8 size corrected.
  10. Sign3D with trestles no longer crashes when over 9 sq m.
  11. Sign3D improvements to sign face scaling and selecting object from 'current drawing' button.
  12. Fix to size border spacing when signs are coloured.
  13. White colours in some older library signs updated to bylayer.
  14. 606 ahead variant added.
  15. 3D signs mounted on rear now adhere to mounting height.
  16. 7001 end with speed limit, now has correct gaps around signs.
  17. 662-1 with variable text, the size of the text has been fixed when in sw.

Version 21.3 - April 2022

Compatibility with R2023:

  1. New Custom User Sign library added, to allow user signs and symbols to be included. Commands ADDSIGNTOLIBRARY and INSERTSIGNFROMLIBRARY now available from the new 'User Signs' menu.
  2. Custom Libraries can be imported and exported to transfer from one PC to another and to re-add libraries into new versions of KeySIGN. Using IMPORTUSERLIBRARIES and EXPORTUSERLIBRARIES commands.
  3. A new CUSTOMPANEL command has been added, to allow non-standard panels to be created and adjusted.
  4. Default installation folder are now 'Transoft Solutions' and a general re-brand of logos and icons to Transoft.
  5. TTM signs scaled to mm sizes now report better sizes in detail blocks.
  6. 3D Sign editing has been improved with various fixes when editing values and sizes.
  7. 3D Sign has been expanded and now has 3D trestles included. This means two or more signs can be added onto a 3D trestle and this will automatically rise to any surface if using Civil AutoCAD.
  8. Ballast Calculations from TMCA guidance are also included with the 3D trestles.
  9. Fixed an issue when opening drawings, which were last save with a paperspace viewport open by default.
  10. National Highways logo added to symbols and also relevant TTM signs.
  11. A new 7306 variant with large work access number added.
  12. A new 7245 for narrow lanes added.
  13. A fix for sw sized signs with a white border displayed.
  14. The advisory min x height is now set to 15.

  8. TTM 7244 has better positioning of lane arrows.

  12. TTM S02_S01 and 2 options fixed.
  13. TTM 7202.1 now has options for a top plate.
  14. Help slides fixed in R2021 and R2022.
  15. ULEZ symbol now correctly drawn and coloured.

Version 21.0 - Dec 2020

New Features

  2. New SIGNSCHEDULE command. Sign Schedules can now be created from selected detail blocks in the drawing.  The schedule columns can be customised to requirements and saved as a template for subsequent schedules.
  3. AutoParking now has 639L, 640.3, 640.4, 660.4, 660.4B, 660.5, 660.5B, 661.1B 660.6top, 660.7top and 661.3A added.

  5. SignAndSuppPlate command now has a 950-1 below a 950, and a 4004 below a 545.1.
  6. 606R and 609R added to thumbnail items.
  7. CAZ symbol now has a dark background version.
  8. Expertise Level has been improved. It is now clearer and has adjustable intermediate settings.
  9. Sign Design Pro direction signs can now be exported to KeyPOST.
  10. Welsh places names can be looked up from a much larger list.
  11. Signs can now be inserted in 3D onto a trestle assembly.
  12. TfL Cycleway Green is now included for cycle route patches and panels.

Fixes

  1. Some duplicated signs in thumbnail menus removed.
  2. Mileages fixed in Autoflag.
  3. Reverse look up of height sign values now handles 6 inch differences better.

Version 20.0 - November 2019

R2016 to R2020 compatibility

  1. The Default transport text now looks more realistic. The previous simple 'stick text' can still be achieved through the settings
  2. Sign and Symbols are now advanced entities. These new objects have much greater control over the 'filled' and 'unfilled' views separately, which wasn't easy with the previous blocks
  3. Roundtrip to KeyPOST now has more images and more data returned into the KeySIGN drawing, including the much-requested wind loading info
  4. X height calculator now refers to the new Chapter 7 appendices
  5. Double clicking on library signs and symbols will give a new properties dialog
  6. The three main representations have been updated and are now named 'Design', 'Outlined' and 'Real'
  7. Height and width signs - will now change to coloured text automatically. There can be changed back and forth using the new representations, so there is no need to explode the signs
  8. Sign detail blocks are now a linked entity. They will update automatically when a sign border is altered
  9. Tigertails type of sign can now be created
  10. Lane signs 868 to 876 can now be create in a dynamic way, giving access to a much large set of variations than the previous fixed library blocks
  11. Lane sign 877 can now also be created in a dynamic way. This allows a huge number of lane variations to be created and now signs can have up to 5 lanes
  12. Tigertail, Sign868 and Sign877 can all be double clicked to edit the signs after creation
  13. Medium and Heavy buttons are more prominent on the ribbon menu
  14. Having a second filled/unfilled sign is now more achievable, with symbols and arrows using representations rather than layers (layers previous affected everything in the drawing)
  15. Sign added for 2712, 551-3 (hedgehog), 2702 (diversion) and 2703 (diverted traffic)
  16. Thumbnail images improved
  17. Motorway gantry junction number and distance (JUNCTIONDIST) has been improved
  18. A new EXPORTTOEPS added
  19. BIM data fields added to Eire speed markings and Yield triangles
